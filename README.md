# Servlet Life Cycle

A simple Java Servlet project demonstrating the **Servlet Life Cycle** using Java, Maven, and Apache Tomcat.

## 📌 Project Overview

This project demonstrates how a Servlet works throughout its life cycle.

The main life cycle methods covered are:

- `init()`
- `service()`
- `destroy()`

It helps understand how a Servlet is created, handles client requests, and is finally removed by the Servlet container.

## 🛠️ Technologies Used

- Java
- Servlet API
- Maven
- HTML
- Apache Tomcat
- IntelliJ IDEA
